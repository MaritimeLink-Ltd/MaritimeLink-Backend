--- GEMINI API (document OCR + company lookup) ---------------------------------
Source: ai.google.dev/gemini-api/docs/pricing (fetched and re-verified
2026-08-17), cross-checked against every call site in this codebase.

  Model in use: "gemini-3-flash-preview" (hardcoded in both
  src/services/geminiService.ts and src/services/companyService.ts).

  [CONFIRMED] Token pricing, from the official rate card:
    Paid tier, per 1M tokens:
      Input:            $0.50  (text / image / video)
      Input (audio):     $1.00
      Output:            $3.00
      Context caching:   $0.05 (text/image/video) / $0.10 (audio)
                          + $1.00 per 1M tokens/hour storage
    Free tier: input, output, and context caching are all free of charge
    (rate-limited — fine for dev/staging, not a production floor).

  This app uses Gemini in TWO structurally different ways, and they are
  priced differently. The original version of this document only modeled
  the first one:

  (A) Document OCR — analyzeDocument() in geminiService.ts. Plain
      generateContent call, no Google Search tool — pure token pricing.
      Confirmed call sites, all hitting Gemini on every request:
        - professionalKycController.ts: 3 call sites (ID front/back, selfie)
          — one-time per professional at onboarding
        - kycController.ts: 3 call sites (ID front/back, selfie) — one-time
          per recruiter/trainer at onboarding
        - professionalDocumentController.ts: 2 call sites — fires on EVERY
          document-wallet upload AND every document replace. This is
          ongoing, not one-time: a seafarer maintaining a wallet of
          certificates (STCW, COC, medical fitness, passport, seaman's
          book, etc.) triggers a fresh OCR call each time they add or
          replace a document, for the life of the account.
      Cost per call (image input, ~1,500 input tokens + ~500 output tokens
      for structured JSON extraction):
        (1,500/1,000,000 × $0.50) + (500/1,000,000 × $3.00) ≈ $0.0023/call

  (B) Company lookup — fetchGeminiCompanyDetails() / getCompanyMetadata()
      in companyService.ts, used only for recruiters/trainers (company
      verification during registration, kycController.ts line ~320,
      recruiterAuthController.ts lines ~352/486/551). This is NOT a plain
      token call — the request body sets `tools: [{ google_search: {} }]`
      (confirmed in companyService.ts), i.e. it uses Gemini's Google Search
      grounding tool. That has its own separate fee on top of token cost.
      [CONFIRMED — grounding pricing, same official page]
        Gemini 3.x models (this app's model family): 5,000 free grounded
        search requests per month, shared across ALL Gemini 3.x usage on
        the account, then $14 per 1,000 requests.
        (For reference only, not what this app uses: Gemini 2.5 models get
        1,500 free requests/day, then $35/1,000.)
      The $14/1,000 (or the free-tier consumption) is charged per search
      query the grounding tool actually performs, which can be more than
      one per API call depending on what the model decides to search for
      — the exact multiplier isn't controllable from our code, so treat
      "1 grounded request per company-lookup call" as a floor, not a cap.
      Checked the frontend (MaritimeLink-Frontend) to see how often this
      fires: RecruiterCompanyDetails.jsx calls it onBlur on both the
      company-name and website fields, plus once more at submit — so a
      single recruiter registration can trigger 3-4+ lookup calls, not 1.
      There is no caching by domain anywhere in companyService.ts, so two
      recruiters from the same shipping company each cost a fresh lookup.
      Token cost per call (~600 input + ~400 output tokens for the
      structured company JSON):
        (600/1,000,000 × $0.50) + (400/1,000,000 × $3.00) ≈ $0.0015/call
        (+ grounding fee once the 5,000/month free pool is exhausted)

  For comparison, the closest stable (non-preview) Flash model is Gemini
  2.5 Flash at $0.30/1M input, $2.50/1M output — cheaper than the preview
  model on token cost alone. Worth keeping as a fallback if Google reprices
  or deprecates the preview model, since OCR doesn't need agentic features.

3. PROJECTION: 100 USERS vs 600 USERS OVER 6 MONTHS
================================================================================
Everything below this line is [ASSUMPTION]-driven, built on top of the
[CONFIRMED] rates above. "Users" here means combined professionals +
recruiters/trainers actively using the platform. I've split the two roles
out for Gemini specifically, since they drive very different call patterns
(professionals: OCR only; recruiters/trainers: OCR + grounded company
lookup). Assumed mix: 90% professionals, 10% recruiters/trainers — typical
for a crewing platform where seafarers vastly outnumber recruiting orgs;
adjust if your actual signup mix differs.

Per-user monthly usage assumptions (replace with real numbers once you have
production data):
  - Phone OTP (Twilio Verify): ~1.5 verifications/user/month (registration +
    occasional re-verification), blended ~$0.06/verification (mostly SMS,
    mixed geography) → ~$0.09/user/month
  - Transactional email (via Namecheap SMTP mailbox, not a metered API):
    ~8 emails/user/month (welcome, OTP-adjacent notifications, booking
    confirmations, status updates) — no per-email cost, but see the sending
    limit flag above
  - Gemini, per professional over 6 months: 3 KYC OCR calls (one-time,
    onboarding) + ~5 document-wallet OCR calls (initial certificates) + ~1
    replace/renewal ≈ 9 OCR calls total ≈ $0.021/professional over 6mo
  - Gemini, per recruiter/trainer over 6 months: 3 KYC OCR calls (one-time)
    + ~4 grounded company-lookup calls (2 field-blur previews + submit +
    one re-edit) ≈ 3×$0.0023 + 4×$0.0015 ≈ $0.0129/recruiter over 6mo
    (grounding fee itself stays $0 at this volume — see below)
  - Supabase storage: ~5 MB/user (KYC docs, selfies, profile photos)
  - Database growth: modest — a few KB per user record plus bookings; not a
    driver at this scale

--- WHAT ACTUALLY DRIVES COST AT THIS SCALE ------------------------------------
  1. Twilio Verify is the single line item that scales most predictably and
     linearly with users — and geography matters a lot (confirm real
     per-country SMS channel fees for your actual user base, not the US
     figure used above).
  2. Stripe fees are excluded from the fixed-cost totals above on purpose —
     they're a % of transaction volume (course prices × bookings), not user
     count, and need a separate GMV-based model once you know expected
     course pricing and booking frequency.
  3. Vercel Hobby and Supabase Free are confirmed compliance/reliability
     risks right now, independent of the 100/600 user question. Supabase
     Free's 500 MB DB / 1 GB storage caps will be hit well before you reach
     600 users if KYC document volume follows the assumptions above —
     budget the $25/mo Pro upgrade as a near-term cost, not a "maybe."
  4. Gemini stays cheap in dollar terms even under the corrected, higher
     call-volume model (~$2/mo at 600 users) — but the call PATTERN matters
     more than the cost: document-wallet OCR is ongoing/unbounded per user
     (not a one-time onboarding cost), and company lookups have no caching,
     so both will keep growing linearly with usage in a way the original
     "2 calls/user/month" placeholder didn't capture. Watch the 5,000/month
     free grounding pool once recruiter signups pick up meaningfully past
     this projection's 6-month/600-user horizon.
  5. Email has no per-message pricing to model here anymore (Namecheap
     mailbox, not a metered API) — but that also means there's no visible
     cost signal if it silently starts throttling at volume. Worth a real
     transactional email provider (Resend, SES, Postmark, etc.) before 600
     users if the mailbox's sending limits turn out to be tight — a
     decision this document flags but doesn't make, since no such provider
     is wired into the code today.
